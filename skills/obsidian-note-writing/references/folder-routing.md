# Folder Routing

| Destination | Use for |
|---|---|
| `Clippings/` | External articles, X posts, webpages, copied references |
| `Codex工作台/` | Codex, agents, skills, MCP, tool workflows, AI workbench notes |
| `技术笔记/` | General technical knowledge, frameworks, languages, databases |
| `项目相关/` | Project requirements, designs, reviews, implementation notes |
| `会议纪要/` | Meeting notes, decisions, action items |
| `daily/YYYY/` | Daily notes and temporary logs |

For Codex-related notes, prefer `Codex工作台/`.
